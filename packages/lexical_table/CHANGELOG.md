# Changelog

## 1.0.0

First stable release; semantic versioning applies from here.
Tables: a resolved grid, merged cells, cell-rectangle selection and every
structural command.

The entries below record how it got here.

## 0.1.0-dev.2

Table editing: the resolved grid (`TableGrid`), cell-range selection, and the
structural operations and commands — insert and delete rows and columns,
merge and split, header toggles, Tab between cells, and Delete over a block
of selected cells.

## 0.1.0-dev.1

First development release. Node types verified as a fixed point against
fixtures generated from Lexical 0.48.0.
