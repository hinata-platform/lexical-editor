# Changelog

## 1.1.0

First release. The packages version in lockstep, so this one joins the set at
its current version rather than at 1.0.0.

The three embeds Lexical has — `youtube`, `tweet` and `figma` — in the
playground's wire format, with upstream's URL recognition, a card widget that
needs no player plugin, and markdown rules for the two kinds upstream drops.
